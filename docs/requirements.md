# Commerce Agents — 功能需求与非功能需求

## 1. 概述

构建一个 AI 驱动的电商购物助手，用户在聊天界面中完成商品搜索、对比、购买。核心差异化在于完整的可观测性（Langfuse）和 KPI 驱动的性能追踪。

---

## 2. 功能需求（Functional Requirements）

### 2.1 需求理解（Demand Understanding）

系统在接收用户输入后，识别并提取以下信息：

| 识别维度 | 示例 |
|---------|------|
| 品类 | "跑鞋"、"手机"、"连衣裙" |
| 品牌偏好 | "耐克"、"Apple"、"不要杂牌" |
| 价格范围 | "800 左右"、"200-300"、"预算不限" |
| 属性规格 | "42码"、"256GB"、"红色" |
| 用户意图 | 搜索、对比、筛选、下单、取消 |

### 2.2 商品检索与展示（Product Search & Display）

**2.2.1 搜索能力**
- 关键词精准搜索（硬性需求）
- 模糊语义搜索（软性需求）
- 基于对话上下文的连续搜索（例如：先搜"跑鞋"，接着说"不要红色的"）

**2.2.2 商品展示**
- 搜索结果按相关性排序，展示 Top-K 个结果
- 商品展示内容根据品类动态调整：

| 品类 | 展示侧重点 |
|------|-----------|
| 服饰/鞋包 | 图片、颜色、款式、材质 |
| 电子产品 | 核心参数（CPU、存储、屏幕）、性能评分 |
| 食品/日用品 | 规格、保质期、成分 |
| 其他 | 默认展示标题、价格、简要描述 |

- 支持用户对展示结果进行追问筛选（如"便宜一点的"、"换个颜色"）

**2.2.3 商品对比**
- 支持多商品并排对比
- 对比维度随品类动态变化

### 2.3 购买决策（Purchase Decision）

- 选择具体规格（颜色、尺寸、数量）
- 生成 Stripe 支付链接
- 确认支付状态并通知用户
- 展示订单摘要

### 2.4 可观测性与评估（Observability & Evaluation）

- **Langfuse 追踪**：每次用户交互的延迟、Token 消耗、调用链路
- **Ragas 评估**：Faithfulness、Answer Relevancy、Context Precision
- **可视化仪表盘**：实时展示 KPI 趋势

## 3. 非功能需求（Non-Functional Requirements）

| 指标 | 目标 | 说明 |
|------|------|------|
| 响应时间 | < 3s | 用户发送消息到收到回复的时间 |
| 搜索准确率 | Top-5 召回率 ≥ 80% | 前 5 个结果包含用户想要的商品 |
| 可用性 | 演示期间 100% | 本地运行，无外部依赖停机 |
| 可观测性覆盖 | 100% 交互被追踪 | 每次 LLM 调用都被 Langfuse 记录 |
| 安全性 | 使用 Stripe 测试环境 | 不处理真实支付信息 |

## 4. 用户交互流程（User Flow）

```
用户输入
    │
    ▼
┌─────────────────────────────┐
│ 需求理解                    │
│ - 提取关键词/属性/意图      │
│ - 区分硬性/软性需求         │
└──────────┬──────────────────┘
           ▼
┌─────────────────────────────┐
│ 商品检索与展示              │
│ - 搜索商品数据库            │
│ - 按品类动态展示            │
│ - 支持追问筛选              │
└──────────┬──────────────────┘
           ▼
┌─────────────────────────────┐
│ 购买决策                    │
│ - 选择规格                  │
│ - 生成 Stripe 支付链接      │
│ - 确认支付状态              │
└─────────────────────────────┘
```

## 5. 技术栈

| 层 | 技术选择 |
|----|---------|
| 前端 | 纯 HTML/CSS/JS（无需构建工具） |
| 后端 | Python + FastAPI |
| LLM | DeepSeek V4（兼容 OpenAI API 格式） |
| LLM 框架 | LangChain（可选） |
| 观测性 | Langfuse（Python SDK） |
| 评估 | Ragas |
| 支付 | Stripe（MCP Server + SDK） |
